# Introduction

## Project Overview

Novel Forge AI is an AI-powered writing system built with Laravel. It generates novel foundations, chapter plans, and chapter content using local AI generation through Ollama.

- **AI-Powered Writing**: Leverages AI to assist in story generation and chapter writing
- **Local AI Generation**: Uses Ollama for local, self-hosted AI model inference
- **Laravel-Based**: Built on Laravel with Vue.js, Inertia.js, and Ziggy.js
- **Database-Driven**: AI brain configuration is managed through the database with config fallback

## System Requirements

### Backend
- PHP 8.2+
- Laravel 13
- Composer

### Frontend
- Node.js
- NPM

### AI
- Ollama
- Qwen3 4B Q4 model

### Hardware Recommendation

Local AI models require sufficient system resources. For Qwen3 4B Q4, a minimum of 8GB RAM is recommended, with 16GB+ preferred for optimal performance.
