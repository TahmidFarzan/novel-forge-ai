# Novel Forge AI

## Overview

Novel Forge AI is a Laravel-based AI-powered writing system for generating stories and chapters using local AI models via Ollama.

## Requirements

- PHP 8.2+
- Laravel 13
- Composer
- Node.js & NPM
- Ollama with Qwen3 4B Q4 model
